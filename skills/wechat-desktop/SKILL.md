# WeChat desktop (macOS)

## Open a chat
1. Bring WeChat.app to the front. If it shows a QR login screen, stop and tell the user to log in on their phone.
2. Press Cmd+F (search), type the contact or group name, wait for results, press Enter.
3. Screenshot. Confirm the chat header shows exactly the intended name before doing anything else.

## Read / summarize
- Unread chats show a red badge in the left list. Open each, screenshot, scroll up with the mouse wheel for older messages.
- Summarize per chat: who, what they want, whether a reply is needed.

## Send
1. Click the input box at the bottom of the open chat.
2. Type the message. For Chinese or long text, paste instead of typing key-by-key if typing produces wrong characters.
3. Press Enter to send (Shift+Enter is a newline).
4. Screenshot and confirm the message bubble appears on the right side.

## Pitfalls
- Never click the "+" / wallet / red-packet / transfer buttons.
- Search may match several people with similar names; pick the exact match, else don't send.
